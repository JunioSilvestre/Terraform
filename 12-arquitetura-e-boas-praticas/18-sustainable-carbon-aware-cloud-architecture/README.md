# Arquitetura Consciente de Carbono e Sustentabilidade em Nuvem

## 1. Cenário de Produção Real
Grandes corporações em NY com metas ambientais estritas (ESG) exigindo redução da pegada de carbono de suas cargas computacionais.

## 2. O Problema Real
Roteamento de processamentos em lote e treinos de inteligência artificial para regiões com matriz de energia renovável mais limpa.

## 3. Arquitetura e Engenharia da Solução
Módulo de orquestração agendando tarefas de processamento assíncrono em regiões e horários com menor intensidade de emissão de carbono.

## 4. Ferramentas e Tecnologias
- **Ecossistema:** Green Cloud, Carbon-Aware Computing, Cloud Sustainability, ESG Governance
- **Padrões:** Infrastructure as Code (IaC), HashiCorp HCL2, GitOps, Zero-Trust Architecture, Clean Architecture

## 5. Exemplo de Execução CLI e Validação
```bash
# Execução direta e validação operacional
python calculate_carbon_footprint.py --region us-east-1
```
