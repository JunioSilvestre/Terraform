# 14-projetos-integradores — Projetos Integradores Completos

Arquiteturas corporativas completas prontas para produção.

## 📂 Subáreas
- [`infraestrutura-completa/`](./infraestrutura-completa) — **Tecnologias:** `terraform, hcl` — VPC + EKS/AKS + Banco Gerenciado + CDN + WAF integrados.
- [`multi-cloud/`](./multi-cloud) — **Tecnologias:** `terraform, hcl` — Conectividade híbrida e recursos orquestrados entre AWS e Azure.
- [`disaster-recovery/`](./disaster-recovery) — **Tecnologias:** `terraform, hcl` — Replicação multi-região e failover automatizado via DNS Route53/Traffic Manager.

## 📌 Fluxo Recomendado
```bash
terraform init
terraform plan
terraform apply
```
