# 13-exemplos-e-laboratorios — Laboratórios Práticos e Exemplos por Nível

Guias passo a passo do básico ao avançado para evolução gradual em Terraform.

## 📂 Subáreas
- [`iniciante/`](./iniciante) — **Tecnologias:** `terraform, hcl` — Primeiros recursos locais, variáveis, outputs e primeiro backend.
- [`intermediario/`](./intermediario) — **Tecnologias:** `terraform, hcl` — Construção e consumo de módulos próprios, multi-region e data sources.
- [`avancado/`](./avancado) — **Tecnologias:** `terraform, hcl` — Dynamic blocks, workspaces, providers customizados e import complexo.

## 📌 Fluxo Recomendado
```bash
terraform init
terraform plan
terraform apply
```
